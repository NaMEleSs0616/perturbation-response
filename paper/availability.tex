\section*{Data and code availability}
All data are public and were obtained from scPerturb \citep{peidli2024} (Zenodo record 13350497, version 1.4); MD5 checksums and retrieval dates for every file are in the repository. The code, configuration files, analysis plan and addendum, exact package versions (\texttt{requirements-lock.txt}), fixed seeds, and the scripts that download and preprocess the data and generate every figure, table and quoted number are at \url{https://github.com/NaMEleSs0616/perturbation-response}. The version described here is tagged \texttt{v1.0-paper}; the per-perturbation results, model predictions and summary tables are attached to that release as an archive with SHA-256 checksums (\url{https://github.com/NaMEleSs0616/perturbation-response/releases/tag/v1.0-paper}). The large intermediate response arrays are not archived because the scripts regenerate them exactly from the public data. SHA-256 hashes of the analysis plan, addendum and configuration files are listed in Supplementary Table~\ref{tab:hashes}. The confirmatory study is reproduced by \texttt{python -m biophysical.cli study run -{}-config configs/study.yaml}, and the post-hoc analyses by the scripts in \texttt{paper/scripts/}.

\section*{Use of AI assistance}
An AI coding assistant (Claude, Anthropic; used through Claude Code) was used extensively in this work. Under the author's direction it wrote most of the software, ran the analyses, generated the figures and tables, and drafted the manuscript and the responses to reviewers. It also searched for and checked references. The author set the research question, made the design decisions, reviewed the code, results and text, and accepted or rejected each change. Every number quoted in the paper is generated by the released scripts rather than typed by hand, so all of it can be checked against the code and public data. The assistant is not an author.
